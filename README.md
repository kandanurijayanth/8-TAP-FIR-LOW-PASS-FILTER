# 8-Tap FIR Low Pass Filter

## Overview

This project implements an 8-Tap FIR Low Pass Filter using Verilog HDL.
The filter coefficients are generated in MATLAB, verified through simulation,
and synthesized using Xilinx Vivado.

## Features

- MATLAB coefficient generation
- Verilog RTL implementation
- Testbench verification
- Vivado synthesis
- Area, Timing and Power analysis

## Tools Used

- MATLAB
- Verilog HDL
- Xilinx Vivado 2025.2
